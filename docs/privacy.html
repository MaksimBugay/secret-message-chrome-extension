Privacy Policy

Secret Message – Encrypted Chat Phrases (Chrome extension) · Last updated on November 2026

  • Your private messages are encrypted in your browser; the server stores only encrypted data it cannot read.
  • No registration, no account, no personal profile.
  • No analytics, no advertising, no tracking, no third-party services.
  • The extension reads page content only when you use it: when you open the widget or convert a text, and while you have auto decoding turned on.
  • Conversation details used to write the public phrase (topic, style, language, message history) are sent unencrypted, as explained below.

1. Introduction

Secret Message turns a private message into an ordinary-looking public phrase, for example a comment under a post. Only people who know the same workspace and password can read the private message behind it. This policy explains what data the Secret Message Chrome extension and the Secret Message service at secure.fileshare.ovh handle, and why.

2. Data collection

We do not collect personal data: no names, e-mail addresses, accounts, contact lists, browsing history, location, or behavioral metrics. The extension has no analytics and sends no usage statistics. The only data that leaves your browser is what is needed to encode and decode secret messages, listed in sections 4 and 5.

4. What is sent to the server when you encode

When you encode a message (Encode message in the widget, or Convert into secret message), the extension sends to https://secure.fileshare.ovh:

  • The encrypted message. It is compressed and encrypted in your browser before sending; the server never receives the message text or your password.
  • The workspace and a SHA-256 hash of the password, so that only requests with the same credentials can retrieve the message.
  • The owner signature, if you set one.
  • Conversation details, used to write a fitting public phrase: topic, style, language and the message history. These are sent unencrypted. The history may contain text from the page you answer: the caption of the post, the comment you reply to, the last message of the chat, or text you selected before opening the widget (private messages shown by auto decoding are left out). It also contains earlier public phrases. Do not put private text into the history.

The server returns the public phrase; the extension puts it into the text box or copies it to the clipboard.

5. What is sent to the server when you decode

Auto decoding is off by default and works only on Facebook, Messenger, VK, LinkedIn and Telegram Web. While you have it turned on and hold the mouse pointer over a text on these sites, the extension sends that text (as a possible public phrase) together with the workspace, the password hash and the owner signature, if set, at most once per second. If the text is a secret message for these credentials, the server returns the encrypted message, which is decrypted in your browser. Texts are not sent while auto decoding is off.

6. What the extension reads on web pages

  • When you open the widget: the text you selected on the page, and the site's address (to choose the topic).
  • When you convert a text: the text in the focused text box, and the caption, comment or last chat message it answers, to add it to the message history.
  • While auto decoding is on: the text under the mouse pointer on the supported sites.

The extension does not read or keep any other page content, passwords you type into websites, or your browsing history.

7. Encryption and security measures

  • Messages are encrypted with AES-GCM using a 256-bit key derived from your password with PBKDF2-SHA-256 (100,000 iterations, the workspace as salt), with a fresh random IV for every message. Without the password, the server or anybody else cannot decrypt them.
  • Saved settings are encrypted with a non-extractable key generated in your browser.
  • All requests use HTTPS. The extension loads no remote code.
  • The owner signature fingerprint (the fingerprint button) is computed in your browser from browser and device characteristics and only its SHA-256 hash is used; it is sent only if you choose to use it as the owner signature.

8. Data retention

The server keeps the encrypted message, the workspace, the password hash and the owner signature, linked to the public phrase, so that the people you share the phrase with can decode it. It cannot read the message. No accounts exist, so the stored data is not linked to your identity. The extension does not keep message histories; it forgets them when the page is closed or reloaded.

9. Cookies and local storage

The extension sets no cookies. It uses browser storage only for the settings and widget state listed in section 3, which stay on your device.

11. Third-party services

No third-party tracking, analytics, advertising or APIs are used. The extension communicates only with the Secret Message service at secure.fileshare.ovh.

12. Use of data

Data handled by the extension is used only to encode and decode secret messages. It is not sold, not shared with third parties, not used for advertising, and not used to determine creditworthiness or for lending purposes. Its use adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

13. Geographic location

The Secret Message service runs on servers in the European Union, and we aim to comply with the GDPR.

14. Your choices

  • Turn auto decoding off with Ctrl+Shift+L or the right-click menu; it is off by default.
  • Remove saved settings by clearing the site data of the site where you saved them.
  • Clear the message history in the widget, or reload the page.
  • Uninstall the extension at any time from chrome://extensions.

Because no personal data or accounts are stored, access, rectification and deletion requests do not apply in the usual way; contact us with any question.

15. Free service, no obligations

Secret Message is free. It is provided "as is", without warranties or guaranteed support. You are responsible for keeping your workspace, password and owner signature safe and for sharing them only with people you trust; lost passwords cannot be recovered.
