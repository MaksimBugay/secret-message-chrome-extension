What it is for

Secret Message lets two or more people talk privately in public places: comments under Facebook, VK or LinkedIn posts, Telegram chats, or any other web page. You write a private message, and the extension turns it into an ordinary-looking public phrase that fits the conversation, for example a friendly reply to the post you are commenting on. Everybody sees just that phrase. Only people who know your workspace and password see the private message behind it.

Everybody sees: Beautiful shot! Saturday works for me — I'll bring the thermos ☕
Your friend sees: Beautiful shot! Saturday works for me — I'll bring the thermos ☕ 👁 Can't talk here — meet me at 7 by the old bridge

No registration and no account are needed: the workspace and password you agree on are all it takes.

How it works

1. EncryptYour message is compressed and encrypted in your browser with your password.
2. StoreThe encrypted message is saved on the Secret Message server, which generates a matching public phrase.
3. PostYou post the public phrase like any other comment or message.
4. DecodeYour friend's extension looks the phrase up and decrypts the message with the same password.

The public phrase is a key to look the message up, not the message itself: the private text is never hidden inside the phrase, so the phrase can read completely naturally. The server stores only encrypted bytes it cannot read.

Quick start

  1. Pin the extensionAfter installing, click the puzzle-piece icon (Extensions) in the Chrome toolbar and the pin next to Secret Message – Encrypted Chat Phrases. Its icon now stays in the toolbar.
  2. Agree on a workspace and passwordOpen a site where you will talk (for example facebook.com), click the Secret Message icon and go to Settings → Encryption. Keep or generate a workspace and enter a password: they are saved automatically. Share both with your friend privately: export the settings and send the file with Secure FileShare file transfer (see Sharing settings safely), or tell them in person. Your friend enters or imports the same values.
  3. Write your private message in a comment boxClick into a comment, reply or chat box and type the private message.
  4. Press Ctrl+Shift+EOr right-click the box and choose Convert into secret message. A moment later the text is replaced with a public phrase that fits the post. Post it as usual.
  5. Your friend reads itYour friend turns on auto decoding with Ctrl+Shift+L (the toolbar icon shows ON) and holds the mouse pointer over your comment: the private message appears right after it, in violet italics.
On a Mac the hot keys use the Control key, not Command: Control+Shift+E.

Features in detail

The widget

Click the toolbar icon, press Ctrl+Shift+Y or choose Create a secret message in the right-click menu to open the Secret Message widget on the current page. The widget is added to a page only then; on the supported sites, the auto decoding script waits until you turn it on.

  • Move it by dragging its header; collapse it to a small pill with the arrow button and expand it again by clicking the pill. Position and state are remembered.
  • Help: the ? button in the header opens this page, the shield button next to it the privacy policy, and the envelope button writes us an e-mail and copies our address, sfile4share@gmail.com.
  • Two tabs: Derivation (the wand: write and encode a message) and Settings (the gear).
  • When the widget opens, the topic follows the site (FB post, VK post, LinkedIn post, otherwise Web chat), and text you selected on the page is added to the message history, so the phrase fits that conversation. Private messages shown by auto decoding are left out of the selection.
  • Without a password the widget opens on Settings → Encryption.
  • Auto decoding pauses while the widget is shown (expanded or collapsed), so it does not change text you are working with.

Encode in the widget

On the Derivation tab, type the private message and click Encode message. The message is encrypted, saved and the public phrase is copied to the clipboard, ready to paste. If the clipboard is not available, the phrase is shown under the button instead. With Append generated phrases to history on, the phrase is also added to the message history.

Convert into secret message

The fastest way: write the private message right in the page's text box (a comment, a reply, a chat message, any text field) and press Ctrl+Shift+E, or right-click the box and choose Convert into secret message. The widget does not need to be open.

  1. Conversation context. The message history is cleared and starts with what you are answering, so the phrase fits it: the caption of the post you comment on, the comment you reply to, or the last message of the open chat (Telegram Web). See Supported sites.
  2. Names stay. A reply starting with the name of the person you answer (VK fills in Anna, ; Facebook and LinkedIn insert a mention) keeps it: only the text after the name is encrypted, and the name (or mention) stays in front of the public phrase.
  3. Encoding. A small note above the text box shows the progress. It uses the widget's current settings: the saved ones, or what you changed in the widget on this page.
  4. Replacing. Your text is replaced with the public phrase; Ctrl+Z undoes it. If you changed the text meanwhile, or the site does not accept the replacement, the phrase is copied to the clipboard instead.

Without a workspace or password, the widget opens on Settings → Encryption and tells you which one is missing.

Auto decoding

On Facebook, Messenger, VK, LinkedIn and Telegram Web, the extension can show the private messages of phrases on the page. It is off by default: turn it on or off with Ctrl+Shift+L or the right-click menu item Auto-decode secret messages. The setting applies to all tabs, and the toolbar icon shows an ON badge while it is on.

  • Hold the mouse pointer over a message or comment for a moment: if it is a secret message for your workspace and password, the private message appears right after it, after a magic-eye icon. The phrase itself stays untouched.
  • It uses the obfuscation settings saved for the site. Once the widget was opened on the page, it uses the widget's fields instead, including unsaved changes.
  • At most one lookup per second; a text found not to be a secret message is not looked up again with the same settings. Failed lookups (offline, server busy) are retried on the next hover.
  • Emoji drawn as images are read as emoji, and a reply starting with a mention is also looked up without the name.

Encryption settings

Settings → Encryption. You and the people you talk to must use the same three values.

Workspace
A name for your shared space, up to 100 characters; it is also part of the encryption key. A random one is generated when the field is empty; Generate makes a new one. Different workspaces keep different groups apart.
Password
Encrypts your messages. Choose a strong one and share it only privately (see Sharing settings safely). The eye button shows or hides it. Without the password nobody, including the server, can read your messages, and they cannot be recovered if it is lost.
Owner signature (optional)
An extra shared value, up to 200 characters. If the sender uses one, readers need exactly the same value to decode. The fingerprint button fills in a value computed from this browser; to share messages with others, give them that value too.

Conversation details

Settings → Conversation details shape how the public phrase reads.

Topic
What the conversation is about. Type anything (up to 500 characters) or pick a preset: FB post, VK post, LinkedIn post, Web chat, Everyday life, Work, Travel, Family, Friends, Technology, Food, Health, Entertainment, Plans.
Style
How the phrase sounds (up to 100 characters): Casual, Friendly, Formal, Professional, Humorous, Romantic, Supportive, Direct, Curious, Storytelling, or your own.
Language
The language of the phrase: English, Spanish, French, German, Portuguese, Russian, Chinese, Japanese, Arabic or Hindi.
Message history
The latest messages of the conversation (up to 1500 characters in total; the oldest are removed first), so the phrase fits in as a natural reply. Edit opens it: append, change or remove messages, or clear the history. The history lives only in the open page: it is never saved in the browser and starts empty after a reload.
Append generated phrases to history
On by default: each new public phrase is added to the history, so the next one continues the conversation.

Save, export, import

  • Save (disk icon) keeps workspace, password, owner signature, topic, style and language for the current site, encrypted in that site's browser storage. Settings are kept per site: set them on each site you use (facebook.com, vk.com, linkedin.com, web.telegram.org…). Saved settings survive reinstalling the extension and are removed when the site's data is cleared. The message history is never saved.
  • Automatic saving: when you change the workspace, password or owner signature (typing, Generate, the fingerprint button or an imported file), all settings are saved a moment later on their own. An empty workspace or password is never saved. Changes to the topic, style or language alone are kept only with Save.
  • Export (download icon) saves the settings, including the history, as a JSON file.
  • Import (upload icon) loads such a file, which is then saved automatically, or a file with only conversation details; click Save to keep those.
An exported file contains your password in plain text. Keep it safe, and never send it through the chat or site you use the secret messages in.

Sharing settings safely

The safe and reliable way to give your friend the settings is the Secure FileShare file transfer: an encrypted, direct transfer from your device to theirs, without registration.

  1. Export your settings with the download icon in Settings.
  2. Both of you open the file transfer page and keep it open; your friend shares the host name shown on their screen with you.
  3. Send the exported JSON file only when both screens show the same security code.
  4. Your friend imports the file with the upload icon in the widget, on each site you talk on; it is saved automatically. Delete the file afterwards.

Privacy and security

  • Encrypted in your browser. The private message is compressed and encrypted with AES-GCM (256-bit key derived from your password with PBKDF2-SHA-256, 100,000 iterations, the workspace as salt) before it leaves the browser. The server never receives the message or the password.
  • What the server receives: the encrypted message, the workspace, a SHA-256 hash of the password, the owner signature if set, and the conversation details used to write the phrase: topic, style, language and the message history. The history is sent as plain text: it holds the caption, comment or chat message you answer, and earlier public phrases. Do not put private text into the history.
  • The public phrase is public. Anybody can read it; only people with the workspace, password and owner signature can read the private message.
  • Stored settings are encrypted in each site's browser storage. The message history is never stored.
  • Auto decoding looks up texts you point at only while it is turned on, and only on the supported sites.

Details: the privacy policy.

Limits

  • Encoding: 20 messages per day from one internet connection (IP address). After that, encoding shows a message and works again the next day.
  • Auto decoding: 1000 lookups per day from one internet connection. Every text checked counts, also texts that turn out not to be secret messages (a text is checked only once). After the limit a notice appears and auto decoding pauses for an hour.
  • Need more? For higher limits, for example 1000 encoded messages per day and unlimited decoding, write to us at sfile4share@gmail.com.
  • Encrypted message: up to 32 KiB, which fits long messages since the text is compressed first.
  • Message history: up to 1500 characters in total; a single message cannot be longer.
  • Workspace up to 100, owner signature up to 200, topic up to 500, style up to 100 characters.
  • Auto decoding looks at texts of 12 to 5000 characters.

Troubleshooting

My friend does not see the private message

Check that auto decoding is on (the toolbar icon shows ON), and that your friend entered exactly the same workspace, password and owner signature on that site: settings are kept per site. Reload the page after saving, then hold the pointer over the comment for a moment.

Convert into secret message does nothing

Put the cursor in the text box first, and check the hot key at chrome://extensions/shortcuts. After installing or updating the extension, reload the tabs that were already open.

"Daily limit reached"

The free service encodes up to 20 messages and answers up to 1000 auto decoding lookups per day for each internet connection (IP address). Try again the next day; to save lookups, turn auto decoding off with Ctrl+Shift+L when you are not reading secret messages. Need more, for example 1000 encoded messages per day and unlimited decoding? Write to us at sfile4share@gmail.com.

"The text could not be replaced"

Some editors refuse changes made by extensions. The public phrase is in the clipboard: select your text and paste.

The phrase does not fit the conversation

Open the widget's Settings → Conversation details and adjust the topic, style or language, or edit the message history so it holds the messages you answer.

The widget does not open

Extensions cannot run on Chrome's own pages (chrome://, the Chrome Web Store, the PDF viewer). Open a regular web page.

I lost the password

Messages cannot be decrypted without it; nobody can recover them. Agree on a new password and use it for new messages.
